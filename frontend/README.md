# Yajnaseni frontend

React (Vite) UI for the Yajnaseni symptom assistant.

## Features

- **Symptom card** - editable chips for cycle gap, acne, hair growth, hair
  thinning, weight change, dark skin patches, pain and bleeding. Tap a chip to
  confirm what the AI understood or correct it (values come from
  `POST /api/extract`).
- **Period calendar** - tap recent period start dates; cycle irregularity is
  computed deterministically in JavaScript (`src/lib/cycleStats.js`, no LLM):
  gaps < 21 or > 35 days are irregular.
- **Triage badge** - Emergency / See a doctor soon / Routine check-up (plus the
  cautious default) straight from the backend rules.
- **Voice input** - Web Speech API for kn-IN, hi-IN, ta-IN, te-IN (and en-IN),
  with a clear error message for every failure mode and typed input as backup.
- **Plain-language explanation** - `POST /api/explain` output in the user's
  language, always with the disclaimer *"This is information, not a
  diagnosis."*
- **Doctor summary** - printable English page (Print / Save as PDF): confirmed
  symptoms, cycle data, questions to ask and tests commonly discussed
  (ultrasound, hormone panel, glucose, HbA1c).
- **Privacy notice** - *"No data is stored."* Calendar dates and chips live in
  component state only; nothing is persisted or sent anywhere except the text
  you choose to analyse.

## Run steps

Prerequisites: Node 18+ and the Yajnaseni backend running (see the root
README).

```bash
cd frontend
cp .env.example .env        # optional; defaults work out of the box
npm install
npm run dev                 # http://localhost:5173
```

In another terminal, start the backend:

```bash
# from the repository root
mvn spring-boot:run         # or: java -jar target/yajnaseni-0.1.0.jar
```

Open http://localhost:5173. Voice input requires a Chromium-based browser and
a microphone; everything else works everywhere.

## Tests

```bash
npm test          # 47 unit/component tests (Vitest + Testing Library)
npm run build     # production build -> dist/
```

## Configuration (`.env`)

| Variable | Default | Purpose |
|---|---|---|
| `VITE_API_BASE` | `http://localhost:8080` | Backend base URL |
| `VITE_VOICE_LANGS` | `en-IN,hi-IN,kn-IN,ta-IN,te-IN` | Voice locales offered |

## Test inputs

The 20 realistic sample inputs (Kannada, Hindi, Tamil, Telugu, code-mixed
Hinglish, including red-flag cases) live in
[src/data/test-inputs.json](src/data/test-inputs.json). They populate the
"Try a sample input" dropdown and the failure-case evidence table
(`docs/failure-case-evidence.md`, regenerated by `scripts/generate-evidence.sh`).
